# Working on Respawn

Use Node 22.12+ or Node 24. Run npm ci, npm test, and npm run build.
Preserve problem IDs and the current product rules in docs/PRODUCT_CONTEXT.md.
Use additive SQL migrations after any migration has been applied.
Keep changes focused; do not rewrite the UI merely to change frameworks.
Never commit .env.local, generated builds, dependencies, or personal records.
